# MAJESTIC LOCAL ROLEPLAY

Стартовый шаблон RP-сервера в стиле **Majestic RP** на платформе RAGE:MP.
Запускается локально с вашего ПК.

## Что внутри

### Дизайн (как у Majestic)
- Глубокий тёмно-синий фон + королевские золотые акценты
- Шрифт Cinzel (Trajan-подобный) в заголовках, Inter в тексте
- Логотип-корона + светящаяся надпись «MAJESTIC»
- Анимированный экран входа с силуэтом города и парящими частицами
- Стеклянные карточки, фирменные градиенты, тонкие золотые разделители
- Боковой HUD c вертикальными шкалами (HP / Броня / Голод / Жажда) — как в оригинале
- Спидометр справа внизу при езде в машине
- Деньги + Банк сверху справа в фирменном Cinzel-стиле
- Кинематографичный экран смерти **WASTED** с обратным отсчётом
- Тост-уведомления с цветовыми статусами

### Игровая админ-панель (F2)
Многотабовая консоль в стиле Majestic Admin:

| Вкладка | Что делает |
|---|---|
| **Обзор** | Дашборд: онлайн / репорты / баны / последние логи |
| **Игроки** | Таблица с HP/броней/деньгами/варнами + 11 действий |
| **Репорты** | Очередь обращений от игроков с кнопками «Взять / Ответить / Закрыть» |
| **История** | Хронология всех наказаний |
| **Баны** | Список банов с разбаном в один клик |
| **Транспорт** | Поиск по модели + 12 быстрых карточек (Zentorno, T20, Adder, LSPD, …) |
| **Телепорты** | 10 готовых точек на карте (LSPD, госпиталь, аэропорт, Vinewood, Chiliad, тюрьма, казино …) |
| **Логи** | Все действия сервера (логин, кики, баны, спавны, смерти) |
| **Сервер** | Версия, порт, режим |

### Функционал игрока
- Регистрация и вход с bcrypt-хешем пароля
- Наличные + банковский счёт
- Шкалы голода и жажды (тикают каждые 60 с; на нуле → урон HP)
- Чат: `/me`, `/do`, `/try` (бросок 50/50), `/b` (OOC), `/pay`
- `/report <текст>` — отправить обращение админу
- 7 уровней админа (как у Majestic: помощник → владелец)
- Первый зарегистрированный с логином, указанным в `config.firstAdmin`, получает 7-й уровень
- Авто-сейв состояния каждые 60 с
- Воскрешение в больнице через 8 с после смерти

### Админ-команды
```
/a <текст>       — админ-чат
/kick <id|login> <причина>
/ban  <id|login> <причина>
/unban <login>
/mute <id> <минут>
/warn <id> <причина>   (3 варна → автобан)
/tp <id>     /bring <id>     /tpc <x> <y> <z>
/giveMoney <id> <сумма>
/setAdmin <id> <0-7>   (только владелец)
/veh <model>   /heal [id]   /armor [id]   /spec <id>
```

## Требования

1. **Лицензионная GTA V** (Steam / Epic / Rockstar).
2. **RAGE Multiplayer client** — https://rage.mp/
3. **Node.js 18+** — https://nodejs.org/
4. **RAGE:MP server files** — https://rage.mp/ (раздел «Server»).

## Установка локально

1. Скачайте `server-files` с https://rage.mp/ → распакуйте, например, в `C:\ragemp-server\`.
2. Скопируйте содержимое **этого репозитория** в папку `C:\ragemp-server\`, заменяя `conf.json`, `package.json` и папки `packages` / `client_packages`.
3. Внутри `ragemp-server` выполните:
   ```
   npm install
   ```
4. Запустите сервер:
   - Windows: двойной клик по `ragemp-server.exe`
   - Linux: `./ragemp-server`

Сервер поднимется на `localhost:22005`.

## Подключение клиента

1. Запустите **RAGE Multiplayer** (`ragemp_v.exe`).
2. Сверху в адресной строке введите `localhost:22005` → Enter.
3. Зарегистрируйтесь с логином `admin` (по умолчанию из `packages/majestic/config.js`) → автоматически получите 7-й уровень.
4. F2 — открыть игровую админ-панель.

## Структура

```
conf.json                       # настройки RAGE:MP сервера
package.json
packages/majestic/
  config.js                     # серверные настройки + список телепортов
  index.js                      # точка входа: события, тики, авто-сейв
  database.js                   # JSON-БД (players/bans/logs/punishments)
  auth.js                       # регистрация / авторизация (bcrypt)
  economy.js                    # деньги / банк
  reports.js                    # система репортов (/report)
  admin.js                      # 16 админ-действий, права по уровням
  commands.js                   # все команды чата
client_packages/
  index.js                      # клиент: HUD-тик, CEF-bridge, F2
  shared/theme.css              # фирменный дизайн-токен
  auth/index.html               # экран входа с городом и частицами
  hud/index.html                # HUD: шкалы + спидометр + деньги
  admin/index.html              # многотабовая админ-панель
  notify/index.html             # тост-уведомления
  death/index.html              # экран смерти WASTED
data/                           # авто-создаётся: players.json, bans.json, logs.json, punishments.json
```

## Кастомизация

- **Изменить ник первого админа**: `packages/majestic/config.js → firstAdmin`
- **Стартовые деньги**: `startMoney`, `startBank`
- **Координаты спавна**: `spawnPos`, `spawnHeading`
- **Скорость голода/жажды**: `hungerThirstTickSec` (в секундах за -1)
- **Добавить телепорт в админку**: дописать запись в массив `teleports`
- **Изменить цветовую тему**: `client_packages/shared/theme.css` → `:root` переменные

## Что это НЕ

Это **не клон** Majestic RP. Полноценный RP-сервер — это работа большой команды на месяцы.
Это скелет с фирменным визуалом и продуманной админкой, на котором можно строить дальше:
система фракций, работ, домов, бизнесов, инвентаря, телефона и т.д. — отдельные модули
для допилки.
