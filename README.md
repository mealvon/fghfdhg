# Majestic-like RP сервер (RAGE:MP)

Стартовый шаблон GTA V RP-сервера в стиле Majestic с встроенной игровой админкой.
Запускается локально с вашего ПК.

## Требования

1. **Лицензионная копия GTA V** (Steam / Epic / Rockstar).
2. **RAGE Multiplayer client** — https://rage.mp/ (установить и хотя бы раз запустить).
3. **Node.js 18+** — https://nodejs.org/ (для серверной части).
4. **RAGE:MP server (Windows / Linux)** — скачать с https://rage.mp/ (раздел "Server").

## Установка

1. Скачайте RAGE:MP server файлы (`server-files`) с официального сайта и распакуйте в любую папку, например `C:\ragemp-server`.
2. Скопируйте содержимое этого репозитория **внутрь** `C:\ragemp-server`, заменив `conf.json`, `package.json` и папки `packages` / `client_packages`.
3. В папке `ragemp-server` выполните:
   ```
   npm install
   ```
4. Запустите сервер:
   - Windows: `ragemp-server.exe`
   - Linux: `./ragemp-server`

Сервер поднимется на `localhost:22005`.

## Подключение клиента

1. Запустите RAGE Multiplayer (`ragemp_v.exe`).
2. В адресной строке сверху введите `localhost:22005` или `127.0.0.1:22005` и нажмите Enter.
3. Войдите в игру.

## Базовая админка

Первый игрок, зашедший в игру с логином, указанным в `packages/majestic/config.js` (`firstAdmin`), автоматически получает максимальный админ-уровень.

Открыть админку: **клавиша F2** (только для админов).

### Команды чата

- `/help` — список команд
- `/me <действие>` — описание действия
- `/do <описание>` — описание окружения
- `/b <текст>` — OOC чат
- `/pay <id> <сумма>` — передать деньги игроку

**Админ-команды:**
- `/a <текст>` — админ-чат
- `/kick <id> [причина]`
- `/ban <id> [причина]`
- `/mute <id> <минут>`
- `/tp <id>` — телепорт к игроку
- `/bring <id>` — телепорт игрока к вам
- `/giveMoney <id> <сумма>`
- `/setAdmin <id> <уровень>` — установить уровень админа (только владелец, lvl 7)
- `/veh <модель>` — заспавнить машину
- `/heal <id>`, `/armor <id>`

## Структура

```
conf.json                 # настройки RAGE:MP сервера
package.json
packages/
  majestic/
    index.js              # точка входа сервера
    config.js             # настройки (порт, имя, первый админ)
    database.js           # простая JSON-БД (data/players.json)
    auth.js               # регистрация / авторизация
    commands.js           # все команды чата
    admin.js              # админ-функции и обработчики панели
    economy.js            # деньги
client_packages/
  index.js                # точка входа клиента
  hud/                    # HUD (деньги, имя, онлайн)
  auth/                   # UI логина/регистрации
  admin/                  # игровая админка (CEF)
data/                     # авто-создаётся, тут лежат сейвы
```

## Дизайн

UI выполнен в тёмно-синей цветовой схеме с золотыми акцентами — узнаваемый стиль
Majestic. Шрифты: системные (Inter / Roboto fallback), без внешних зависимостей.

## Что это НЕ

Это не клон Majestic. Это **скелет**, на котором можно строить свой RP-проект:
система фракций, работ, домов, бизнесов, инвентаря и т.д. требует доработки.
